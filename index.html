Backup e restauração

Os dados ficam neste aparelho. Limpar os dados do navegador, desinstalar o aplicativo ou trocar de aparelho pode apagar os registros locais. Exporte backups regularmente e teste a restauração.

Sobre o armazenamento

Esta versão usa armazenamento local do navegador e não envia suas vendas para um servidor. Ela não sincroniza automaticamente com outros aparelhos. Faça um backup antes de atualizar o navegador ou migrar de aparelho.

Para instalar como PWA, hospede os arquivos em um endereço HTTPS uma única vez, abra no Chrome e use o menu “Instalar app” ou “Adicionar à tela inicial”. Depois que os arquivos forem armazenados, as funções principais podem operar offline. Abrir o arquivo HTML diretamente não habilita o service worker.
